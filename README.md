AR/VR Researcher @ NYU HSRN / Technical Lead @ Urban Arts Founders Lab

## Projects

- [**Rewind**](https://github.com/dynotics/Rewind): Spend-control diagnostic for Rho corporate cards that detects policy gaps, backtests proposed rules against transaction history, and flags false positives (TypeScript)
- **Corelink AR/VR networking**: C# WebSocket + TCP receiver clients on NYU's Corelink server for low-latency multi-user sync; IK-based bone synchronization in Unity for shared avatars (NYU High-Speed Research Network)
- **Sketch-to-level procedural generator**: Unity tool that turns player-drawn sketches into generated game layouts. Custom C# pipeline on URP (Stuyvesant × Google mentorship)
- **Roku screensavers**: 4 animated screensavers in BrightScript/SceneGraph, profiled and debugged over telnet for cross-device compatibility on Roku Stick hardware
- [**HairwayToHell**](https://github.com/dynotics/HairwayToHell): GGP 2025 game jam entry (Unity, C#)
- [**ggj-2026-mask**](https://github.com/samsonahh/ggj-2026-mask): Global Game Jam 2026 entry (Unity, C#)
- [**dynotics.github.io**](https://github.com/dynotics/dynotics.github.io): Portfolio site, Astro + Tailwind
